# PGD-AIML Portfolio
A collection of advanced AI and Machine Learning projects showcasing practical applications across different domains.

## Projects

### 1. Natural Language Processing
**Text Classification Project**
- Developed models for text classification using GloVe embeddings and Sentence Transformers
- Best Performance: GloVe with AdaBoost model achieved highest accuracy and F1 score
- Key Features: Balanced performance across metrics, strong generalization to unseen data

### 2. Computer Vision 
**Plant Seedlings Classification**
- Built CNN models to classify 12 different plant seedling species
- Achieved 93% accuracy using data augmentation techniques
- Key Findings:
  - Simple CNN with quality data preparation outperformed complex architectures
  - 64x64 pixel images proved sufficient for high accuracy classification
  - Data augmentation effectively addressed class imbalance issues

Business Impact:
- Enables automated early-stage weed detection
- Potential 30-60% reduction in herbicide usage through precision application
- Mobile application potential for field-based identification

### 3. Neural Networks
**Customer Churn Prediction**
- Developed models to predict credit card customer churn
- Model Performance: 86.5% accuracy with balanced metrics across precision and recall
- Key Insights:
  - Higher churn risk in 45-60 age group
  - Two products optimal for retention (7.6% churn rate)
  - Geographic variations (Germany: 32.4% vs France/Spain: ~16.7%)

### 4. Advanced Machine Learning
**Credit Card Users Churn Analysis**
- Built ensemble models for predicting customer attrition
- Best Model (AdaBoost with Undersampling):
  - Accuracy: 93.4%
  - Recall: 97.0%
  - Precision: 72.1%
  - F1 Score: 82.7%

Key Findings:
- Transaction patterns strongest predictors of churn
- Changes in spending behavior crucial early warning signs
- Customer engagement metrics highly influential
